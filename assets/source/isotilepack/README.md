# Source pack input

This directory is the configured drop-in location for the **Small 128×64** CC0 edition of Screaming Brain Studios' Iso Tile Pack. The upstream archive cannot be redistributed from this repository; download it from the creator and place its PNG tiles under this folder (preserving filenames/subfolders). Do not put the Large 256×128 variant here. The eight files in `demo/` are original CC0 pipeline fixtures, not the commercial pack.

Upstream: https://screamingbrainstudios.itch.io/isotilepack (CC0; retain the creator's notice when bundling their art).
